# Discord-бот управления фракцией ФСВНГ (Army Bot)

Приватный Discord-бот, разработанный для автоматизации кадровых, логистических и административных процессов внутри виртуальной фракции войск национальной гвардии (ФСВНГ). Бот работает в режиме Single-Guild и интегрирован в инфраструктуру проекта.

## 🌟 1. Описание функционала
*   **Кадровый документооборот:** Интерактивные UI-панели (Views/Modals) для подачи рапортов (ПСЖ, переводы между подразделениями, повышения, восстановления через переаттестацию, отпуска IC/OOC, отгулы, запросы ролей, подтверждение военных билетов).
*   **Иерархия и доступ:** Автоматическая выдача/снятие ролей, форматирование никнеймов в соответствии с должностью, подразделением и званием (с учётом позывных СОБР и статусов отпуска). Проверка наличия военного билета для офицерских званий (Мл. лейтенант+).
*   **Склад и логистика:** Заказ снабжения с подсчётом лимитов по категориям и кулдауном (6 часов), аудит склада (выдача и очистка), а также отчёты о продаже материалов.
*   **Управление нарушениями:** Модуль Чёрного Списка (ЧС) с автоматическим расчётом неустойки (14 дней ЧС при увольнении, если боец прослужил менее 5 дней), авто-увольнение при выходе бойца с Discord-сервера.
*   **Спецподразделения:** Запрос формы СОБР для совместных патрулей с автоматической проверкой знаний правил ношения формы (тестирование со случайным пулом вопросов).

## ⌨️ 2. Список команд
**Slash-команды (App Commands):**
*   `/blacklist add [военнослужащий] [дни] [причина] [доказательства]` — Внесение в ЧС (Доступ: Капитан+, звание выше цели).
*   `/blacklist remove [военнослужащий] [причина]` — Вынесение из ЧС (Доступ: Капитан+, звание выше цели).
*   `/blacklist list` — Постраничный просмотр активного чёрного списка.
*   `/members [подразделение]` — Постраничный просмотр личного состава подразделений с подсветкой отсутствующих на сервере и просрочек в Академии (Доступ: Капитан+).

**Контекстное меню (ПКМ по пользователю -> Приложения):**
*   `Отредактировать` — Изменение имени, статика, звания, подразделения и должности бойца.
*   `Повысить (+1 зв.)` — Быстрое повышение на 1 порядковое звание (с проверками дисциплинарных ограничений и военного билета).
*   `Уволить` — Увольнение с указанием причины (с логированием и снятием служебных ролей).

**Admin-команды (Префиксные, только для сервисных аккаунтов):**
*   `!resync` — Принудительная синхронизация дерева команд с сервером.
*   `!reset_division <discord_id>` — Сброс подразделения и должности пользователя в БД.
*   `!refresh_roles`, `!refresh_dismissal`, `!refresh_promotion`, `!refresh_transfer`, `!refresh_reinstatement`, `!refresh_leave`, `!refresh_timeoff`, `!refresh_supplies`, `!refresh_audit`, `!refresh_materials`, `!refresh_patrol`, `!refresh_military_id` — Обновление закреплённых UI-панелей в соответствующих каналах.

## 📚 3. Используемые библиотеки
*   `discord.py` — Базовый асинхронный фреймворк для взаимодействия с Discord API (включая `app_commands`, Dynamic Items и LayoutViews).
*   `beanie` — Асинхронный ODM для MongoDB на базе Pydantic.
*   `motor` / `pymongo` — Асинхронный драйвер и низкоуровневые атомарные операции (`find_one_and_update`, `bulk_write`).
*   `pydantic` — Строгая валидация схем данных.
*   `dateparser` — Распознавание дат на естественном языке для модуля отпусков.
*   `sentry-sdk` — Мониторинг исключений и трекинг ошибок.
*   `python-dotenv` — Загрузка конфигурации из переменных окружения.

## 🛡 4. Требуемые права (Permissions) и Интенты
Бот спроектирован с учётом принципа минимальных привилегий (Регламент п.4).

**Необходимые Discord Intents (Интенты):**
*   ✅ `Server Members Intent` — Требуется для синхронизации ролей, проверки присутствия бойца на сервере и обновления никнеймов.
*   ✅ `Message Content Intent` — Требуется для обработки административных префиксных команд (`!refresh_...`, `!resync`).
*   ❌ *Privileged Presences Intent — НЕ требуется и отключен.*

**Необходимые права бота (Bot Permissions):**
*   `Manage Roles` (Управление ролями) — Выдача и снятие ролей званий, должностей и подразделений.
*   `Manage Nicknames` (Управление никнеймами) — Установка формата `[АВНГ] Р-й | Имя Фамилия`.
*   `Read Messages / View Channels` — Доступ к служебным каналам.
*   `Send Messages / Send Messages in Threads` — Публикация рапортов и логов.
*   `Manage Messages` — Удаление старых сообщений интерфейса при обновлении закреплённых панелей.
*   `Embed Links` & `Attach Files` — Формирование карточек аудита, рапортов и заявлений.

## 📊 5. Логирование и Аудит (согласно п. 7.3 Регламента)
Бот ведёт двойное логирование всех критических действий:
1.  **Локальные логи (Системные):** Запись событий, предупреждений и ошибок в `bot.log` и `stdout` через стандартный модуль `logging`, а также отправка непредвиденных исключений в `Sentry`.
2.  **Discord-Аудит (Игровые и кадровые действия):** Все ключевые изменения (принятие, увольнение, повышения/понижения, смена должности или подразделения, выдача склада, наложение ЧС, самостоятельное изменение данных) логируются в специальные каналы (`audit`, `storage_audit`, `blacklist`, `static_log`) через модуль `services/audit.py`. Записи содержат упоминания сторон, даты, статики и прямые ссылки на сообщения.

## 🚀 6. Инструкция по развертыванию

### Шаг 1: Инфраструктура Discord
Для работы бота на сервере должны быть созданы соответствующие каналы (ID указываются в `core/config.py`):
*   Каналы для логов: *Кадровый аудит (`audit`), Аудит склада (`storage_audit`), Лог статика (`static_log`), Чёрный список (`blacklist`).*
*   Каналы для рапортов и заявлений: *Запрос ролей (`role_getting`), Увольнения (`dismissal`), Восстановления (`reinstatement`), Отгулы (`timeoff`), Запрос склада (`storage_requests`), Отпуска IC/OOC (`ic_leave`, `ooc_leave`), Патруль СОБР (`patrol`), Продажа материалов (`materials`), Военный билет (`military_id`), каналы рапортов подразделений.*
